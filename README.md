# NEXUS — Timothy Praise

**Developer.Musician** · Personal sci-fi live wallpaper concept.

[⬇️ **Download NEXUS as a ZIP**](https://github.com/timo1456/Wallpaper/archive/refs/heads/main.zip)

## Run it on Windows

1. Open the repository and click **Code → Download ZIP**, or use the download link above.
2. Extract the ZIP to a folder.
3. Open the extracted folder.
4. Double-click `index.html` to run the wallpaper preview in your browser.

No Node.js, Python, build step, or internet connection is required for the local preview. Keep `index.html`, `styles.css`, `script.js`, and `background.svg` together in the same folder.

## Use it as a live wallpaper

For a desktop wallpaper, install [Lively Wallpaper](https://github.com/rocksdanister/lively) from its official project page. In Lively, add the local `index.html` file as a wallpaper (the exact menu wording may vary by version). You can also run the page directly in Edge or Chrome to preview it.

## Features

- Original vector sci-fi background featuring **TIMOTHY PRAISE — DEVELOPER.MUSICIAN**
- Random, decorative terminal-style activity feed
- Animated CPU, GPU, and memory bars
- Clickable music dock that opens a centered full-screen-style music interface
- Load and play an audio file from your own computer; the file is not uploaded anywhere
- Clock, responsive layout, and reduced-motion support

## Important hardware meter note

The current CPU/GPU/RAM bars are **simulated demo values**, not actual Windows telemetry. Ordinary browser-based HTML/CSS/JavaScript cannot directly read Windows CPU and GPU utilisation for privacy and security reasons. Genuine readings would require a separate native Windows helper/bridge or a wallpaper host integration that exposes system telemetry. The terminal is also decorative simulation, not a real hacking tool.

## Performance

The background is a lightweight SVG image and the effects use CSS animations. Actual power use depends on the wallpaper host, display resolution, and system configuration. Pause the wallpaper while gaming or running demanding audio software if needed.
